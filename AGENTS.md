# Contributor boundaries

Use Python 3.12 and `uv sync --frozen --all-extras --dev`. Run `make validate`.
Keep local execution deterministic and network-free; never infer Azure success.
Do not turn documentation or synthetic evidence into a live-validation claim.
All business actions stay behind policy and exact, expiring, independent approval.
The supplied writer only records DRY_RUN receipts.

Do not deploy, publish, push, change consent, alter identities or modify cloud
settings without explicit authorization. Do not copy unlicensed source or
confidential content. Private configuration belongs in ignored `.env`.

If you are in VS Code, read the vscode-microsoft-foundry skill first.
