# Lifecycle governance and application authority

Agent ownership, sponsorship, inventory review, lifecycle status and consent
belong to applicable Entra/Agent 365 governance surfaces. This accelerator
provides evidence verification and operator guidance, not a replacement tenant
control plane.

Business-action authority stays in deterministic application policy and the
independent approval service. A registry entry, model answer, evaluator score or
owner label cannot authorize a write. Approval binds the exact proposal
fingerprint, subject, scope and expiration and is validated before a DRY_RUN receipt.

Review owner changes, abandoned agents, access, evidence retention and incident
handling with native administrators. No automatic remediation is enabled.
Local operator attestations expire after 24 hours and require the configured
tenant/agent scope; completeness is not Microsoft certification.
