# Purview signal scope

Purview classification, information protection, audit and DLP are native controls
with workload-, cloud-, policy- and license-specific support. The application's
redaction and synthetic classification are not enterprise DLP integration.

Do not treat an Agent Registry entry, Application Insights span or successful
model evaluation as a Purview audit/DLP observation. Verify the supported data
path and policy, use approved synthetic content, and retain actual product evidence
with time and scope before making a claim.

No Purview connector, label publication, audit search or DLP policy mutation is
implemented. If the feature cannot be observed, keep it VERIFICATION_REQUIRED;
the local lab may demonstrate application redaction only.
