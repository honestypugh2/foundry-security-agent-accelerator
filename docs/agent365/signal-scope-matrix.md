# Signal scope matrix

| Surface | Actual implemented evidence | What it cannot prove |
|---|---|---|
| Application | Audit chain, DRY_RUN receipt, stage spans | Absence of all uninstrumented actions |
| Foundry | Pinned prompt-agent SDK adapter; service evaluator adapter | Successful service execution until authorized and observed |
| Azure Monitor | Export delivery status; read-only scoped workspace rows | Agent 365 ingestion or Microsoft security-product coverage |
| Agent 365 settings | Read-only preview account fields, when explicitly selected | Registry presence, owner/sponsor correctness or activity ingestion |
| Agent 365 evidence | Scoped fresh operator attestation completeness | Authenticity of remote portal/API observations |
| Entra | Caller tenant guard | Agent identity creation, tenant policy or role correctness |
| Defender | Operator integration checklist only | Alert, incident, prevention or correlation |
| Purview | Operator integration checklist only | Native audit, classification or DLP enforcement |

No failed Foundry evaluation is assumed to generate a Defender alert. No registry
entry is assumed to prove Purview coverage. Native enforcement remains native.
