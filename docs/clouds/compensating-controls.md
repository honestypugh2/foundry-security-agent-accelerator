# Compensating controls

If a native capability is unavailable, record the missing control, affected data
and threat, proposed compensating control, owner, evidence and expiration.
An authorized risk owner must decide acceptance; a model cannot waive the gap.

Examples: retain network-free synthetic data instead of uploading across clouds;
use local OTel JSON plus an approved private evidence store while ingestion is
unavailable; require manual review while an integration is not observable.

These are not equivalent to Agent 365 governance, Defender prevention, Purview DLP
or service-backed Foundry evaluation. Missing critical enforcement blocks release.
No automatic commercial routing, synthetic "live" proof or credential escalation
is a valid compensating control. [Release gates](../evaluations/release-gates.md).
