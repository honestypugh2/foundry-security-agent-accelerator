# Feature availability is not endpoint syntax

| Capability | Commercial | Government |
|---|---|---|
| Local synthetic workflow and HTML | Local, cloud-independent | Local, cloud-independent |
| Foundry prompt agent | Adapter implemented; live verification required | Endpoint routing supported; service/API availability unverified |
| Search / Content Safety | SDK adapters implemented; tenant/service authorization required | Cloud suffixes validated; features/regions/RBAC require verification |
| Foundry model-judged evaluation | Implemented, explicit authorization | Rejected until supported route verified |
| Azure Monitor / Log Analytics | Export/query implemented; ingestion unobserved | Configured cloud endpoints; service availability unverified |
| Agent 365 / Defender / Purview | Capability-specific license/consent/observation required | VERIFICATION_REQUIRED; no commercial parity assumption |

Check current official product, regional and government documentation immediately
before a live event. Package installation and Bicep compilation establish none
of these live availability claims.
