# Attack success rate limitations

No population-level ASR is measured by the supplied fixtures. They are targeted
regressions for evidence interpretation and enforcement invariants.

Any future ASR report must define attack population, attempted actions, observed
execution, harmful outcome, denominator, sampling, tool access, policy/model
versions and confidence/uncertainty. A blocked attempt, safe response, missing
trace and actual unsafe execution are different observations.

Do not invert an unfamiliar SDK score, average away critical failures, treat
unknown execution as a failed attack or assume refusal text means no side effect.
Model-judged relevance/groundedness quality is not an attack-success metric.
[Verdicts](verdict-semantics.md), [release gates](release-gates.md).
